# 调色运算在编码空间进行

显示层 Gamma Ramp 的输入是显示器码值，下游不存在任何色彩管理。另一条路是先做 sRGB 解码、在线性光空间运算再编码：物理上更正确，但要先假定游戏输出的传递函数，而这个假定无从验证，猜错的结果比不做更糟。参照产品还把 Exposure（不动白点）与 Brightness（推白点）区分为两个独立滑杆，这两个语义在线性光下会塌缩成同一个。

决定所有算子在归一化码值空间直接运算，不做传递函数解码。

## Consequences

- 不提供物理意义上的曝光，亮度只有加性偏移一种语义。
- 预设数值无法与任何线性光调色工具互迁。
- 每个算子是一元标量函数，可脱离显卡单独测试。
